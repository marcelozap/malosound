# MaloSound.ai website

The active website direction is documented in [WEBSITE_DIRECTION.md](WEBSITE_DIRECTION.md).
The exact public deploy command, preview instructions, and release boundary are in [DEPLOY.md](DEPLOY.md).

MaloSound.ai now uses the approved black, silver, violet, and ice-blue identity with
**price, played back.** and a short project description. The automatic audiovisual
generator is still in development.

The old journal workflow is retired from the public site. Journal source, trading
records, reports, and music-lab pages are excluded from the build. No journal
refresh, audio download, or data intake runs during deployment. Preserve private
source material locally; never expand the public allowlist to copy the repo.

The domain continues to use origin/master → Vercel → malosound.ai. The separate
private Sites preview does not change the custom domain.
